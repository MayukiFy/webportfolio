## 🌟 หน้าของเว็บไซต์ (Pages)

- **Home (`index.html`)**: หน้าแรกพร้อม Hero Section, Profile Glowing Aura, Quick Navigation Hub และผลงานไฮไลต์
- **About Me (`about.html`)**: ประวัติย่อ, ปรัชญาการออกแบบ, ไทม์ไลน์การศึกษาสาขาสื่อนฤมิต (เกียรตินิยมอันดับ 1), ความสนใจ และเป้าหมายการทำงาน
- **Skills (`skills.html`)**: รวม 10 ทักษะมัลติมีเดีย, ตัวกรองหมวดหมู่, แถบวัดระดับความเชี่ยวชาญ และ Creative Toolset
- **Portfolio (`portfolio.html`)**: แฟ้มสะสมผลงาน 6 ชิ้นเอก, ระบบตัวกรอง, พร้อม Bootstrap Modal แสดงรายละเอียดเชิงลึก
- **Contact (`contact.html`)**: ช่องทางติดต่อ, ปุ่มคัดลอกอีเมล 1 คลิก, ลิงก์โซเชียล และแบบฟอร์มส่งข้อความ

## ✨ คุณสมบัติเด่น (Features)

- 🌓 **Dark / Light Mode**: สลับโหมดการแสดงผลได้ทันที พร้อมจดจำสถานะผ่าน `localStorage`
- 💎 **Glassmorphism Design**: เอฟเฟกต์กระจกฝ้าโปร่งแสง สวยงาม มีระดับ
- 📱 **Fully Responsive**: รองรับทั้งจอสมาร์ทโฟน แท็บเล็ต และคอมพิวเตอร์เดสก์ท็อป
- 🧭 **Active Route Highlighting**: ระบบตรวจจับหน้าปัจจุบันและไฮไลต์เมนูนำทางให้อัตโนมัติ
- ⚡ **Butter-smooth Animations**: Scroll Reveal ด้วย native `IntersectionObserver API`
- 📋 **One-click Copy Email**: คัดลอกอีเมลลงคลิปบอร์ดได้ทันที พร้อมข้อความแจ้งเตือน

## 🚀 การเปิดใช้งานออนไลน์ผ่าน GitHub Pages

1. ไปที่แท็บ **Settings** ของ Repository บน GitHub
2. เลือกเมนู **Pages** ในแถบด้านซ้าย
3. ในหัวข้อ **Build and deployment > Branch**:
   - เลือก Branch: `main`
   - เลือก Folder: `/ (root)`
4. กดปุ่ม **Save**
5. รอระบบประมวลผลประมาณ 1-2 นาที คุณจะได้ URL สำหรับเปิดดูเว็บไซต์ออนไลน์ได้ทันที เช่น:
   `https://<your-username>.github.io/<repository-name>/`
